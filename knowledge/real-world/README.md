## 目录说明

本目录用于存储 **BOS-FS 真实交付过程中的案例、经验教训和最佳实践**。

与 `examples/` 目录中的假设性示例不同，这里的每个文件都来自**真实项目交付**，经过脱敏处理，包含实际踩坑经验和可复用的产出物。

## 存储内容

| 类型 | 说明 | 示例 |
|------|------|------|
| 交付案例 | 完整的项目交付过程记录 | `pen-test-lessons.md` |
| 踩坑经验 | 实际遇到的问题及解决方法 | 各案例中的"踩坑经验"章节 |
| 反模式 | 在实践中发现应避免的做法 | 各案例中的"反模式"章节 |
| 可复用产出 | 从实际交付中沉淀的脚本/模板/检查清单 | 各案例中的"可复用的产出"章节 |

## 如何贡献

1. 复制 [`template.md`](./template.md) 为新文件
2. 填写所有必填字段（项目背景、交付过程、踩坑经验等）
3. 确保项目信息已脱敏（不含客户名称、敏感数据等）
4. 标注可信度等级（参考 [内容质量评级规范](../governance/content_quality_rules.md)）
5. 提交到本目录

### 必填字段

- `可信度` — 文档可信度等级
- `项目` — 脱敏后的项目描述
- `交付时间` — YYYY-MM 格式
- `作者` — 文档作者
- `背景` — 真实项目背景
- `交付过程` — 实际交付步骤
- `踩坑经验` — 至少一条实际问题记录

## 与文档生成的集成

在使用 `doc-generator` SKILL 生成文档时，本目录中的案例可作为**真实素材**注入，提升生成内容的可信度和实用性。

- SKILL 位置: `skills/doc-generator/SKILL.md`
- 使用方式: 在文档生成指令中引用 `knowledge/real-world/` 下的相关案例文件
- 效果: 生成的文档将引用真实交付数据而非假设性示例
